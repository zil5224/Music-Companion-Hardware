# 数据与隐私

Music Companion 是个人本机应用：除你自己配置的模型服务外，没有中转服务器，也没有账号体系。

## 设计约束

- 网页服务与内置音乐服务默认只监听 `127.0.0.1`，并校验请求来源；**不要**绑定公网地址或通过反向代理公开（目前没有公网多用户鉴权）。
- 模型 API Key 只保存在本机 `.env`（或启动它的进程环境变量），只由服务端读取；浏览器拿不到 Key。
- 内置网易云音乐服务作为独立子进程运行，只接受应用用到的接口，子进程环境里已删除模型 Key。
- 长期记忆与自动备份只允许本机同源访问，并用 `HttpOnly` + `SameSite=Strict` 的浏览器身份 Cookie 隔离。

## 数据在哪里

| 数据 | 位置 | 谁能读到 |
|---|---|---|
| 聊天、收藏、播放历史、歌单、偏好、网易云登录凭证 | 当前浏览器的 `localStorage` | 本机同一浏览器配置 |
| 长期记忆 | Windows 默认 `%LOCALAPPDATA%\Zily\memory` | 本机、对应浏览器身份 |
| 自动备份 | 记忆目录旁的 `backups`（`ZILY_BACKUP_DIR` 可改） | 本机文件系统 |
| 程序配置与模型 Key | 项目根目录 `.env` | 本机 |
| 硬件通信 | USB 串口，只在本机浏览器与设备之间 | 本机 |

## 会发给模型服务的内容

- 聊天：当前对话（含你设置里允许的近期上下文）与开关打开时的记忆引用。
- 会话摘要：后台整理当前会话摘要时会发送相关对话。
- 联网搜索：查询词与最近一轮相关问答；是否附带上下文取决于是否有指代。
- 自动发现记忆：符合条件的用户原话会发送给模型生成候选，由你确认后才保存。
- 智能歌单：本轮需求，可能附带有限的已有歌单作为风格参考。

模型服务由你自己选择并承担费用。请阅读对应平台的隐私条款。

## 凭证检测

聊天发送、保存快照与摘要、手动记忆、自动发现和备份在写入前都会检查常见凭证形态（`sk-` 开头的 Key、Bearer、私钥、Cookie 等），命中时拒绝处理或替换为占位符。检测覆盖常见格式，**任意无前缀字符串、拆分或编码后的秘密仍可能无法识别**。如果曾经粘贴真实凭证，请撤销并轮换它，并检查已有聊天、记忆、日志与手动备份。

## 截图、录屏与演示素材

仓库里的界面截图与实机演示视频由项目作者在自己的电脑上录制，已去除音轨与文件元数据，并逐帧检查不含账号名、聊天隐私或文件名。你制作自己的演示素材时，请先检查画面中是否有 Key、会话内容、桌面文件名或通知弹窗。

## 删除与恢复

- 单条删除与清空会更新删除标记或清空代次，并同步处理应用管理的相关备份。
- 「数据管理」导出的备份是明文 JSON，含私人内容；导入前会先预览结构与冲突。请妥善保管，或移出电脑自行加密。
- 清空本机数据后，已单独下载的备份副本仍需自行处理。
- 换电脑时用导出的备份恢复；恢复后刷新页面。

## 硬件侧

- 串口访问由浏览器授权，页面只能使用你选择过的设备。
- 固件不存储个人信息，只在内存中保留当前显示用的歌名、歌手、进度与状态。
- 同一浏览器同一时间只允许一个标签页占用串口；多标签页通过 Web Locks 互斥。
